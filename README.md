# 🛒 React eCommerce Website

A modern and responsive eCommerce web application built using **React, Vite, Tailwind CSS, and React Router**.  
This project allows users to browse products, filter by category, search items, and view detailed product pages.



## 🚀 Features

- 🏠 Home page with image slider (category navigation)
- 🔍 Search functionality for products
- 📂 Category-based product filtering
- 🛍️ Product listing with ratings and price
- 📄 Product detail page
- 🛒 Cart page (add/remove items)
- 🔐 User authentication (Login/Logout)
- 🌙 Fully responsive (Mobile + Desktop)



## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Icons:** React Icons
- **State Management:** useState, useEffect
